# Node Mapping Reference

## GoogleGeminiDirect (from comfyui-local-gemini)

Replaces: `GeminiImage2Node`, `GeminiNanoBanana2`, `GeminiNanoBanana2V2`

### Inputs

| Name | Type | Required | Widget | Notes |
|------|------|----------|--------|-------|
| `api_key` | STRING | yes | yes (0) | Leave empty; use `GOOGLE_GEMINI_API_KEY` env var |
| `prompt` | STRING | yes | yes (1) | Multiline prompt text |
| `model` | COMBO | yes | yes (2) | See model list below |
| `seed` | INT | yes | yes (3) | Default 42. Has `control_after_generate=True` which adds a hidden control widget (4) |
| `aspect_ratio` | COMBO | yes | yes (5) | Options: `auto`, `1:1`, `2:3`, `3:2`, `3:4`, `4:3`, `4:5`, `5:4`, `9:16`, `16:9`, `21:9` |
| `resolution` | COMBO | yes | yes (6) | Options: `1K`, `2K`, `4K` |
| `response_modalities` | COMBO | yes | yes (7) | Options: `IMAGE+TEXT`, `IMAGE` |
| `images` | IMAGE | no | no | Optional batched input images (up to 14). Was `image` (singular) in older versions. |
| `system_prompt` | STRING | no | yes (8) | Defaults to `GEMINI_IMAGE_SYS_PROMPT` |

**Widget order (9 values):**
```
[0] api_key
[1] prompt
[2] model
[3] seed
[4] seed_control  (auto-generated by control_after_generate, not in INPUT_TYPES)
[5] aspect_ratio
[6] resolution
[7] response_modalities
[8] system_prompt
```

### Outputs
| Name | Type | Slot | Notes |
|------|------|------|-------|
| `response` | STRING | 0 | Text response from Gemini |
| `image` | IMAGE | 1 | Generated image when `response_modalities` includes `IMAGE`; black placeholder if none returned |

### Model Options

| Model | Display Name | Supports Image Gen |
|-------|-------------|-------------------|
| `gemini-3.1-pro-preview` | 3.1 Pro Preview | no |
| `gemini-3-pro-preview` | 3 Pro Preview | no (mapped to `gemini-3-pro-image-preview` at runtime) |
| `gemini-3-pro-image-preview` | Nano Banana Pro | **yes** |
| `gemini-3.1-flash-image-preview` | Nano Banana 2 | **yes** |
| `gemini-2.5-flash-image` | Nano Banana | **yes** |
| `gemini-3-flash-preview` | 3 Flash Preview | no |
| `gemini-2.5-pro` | 2.5 Pro | no |
| `gemini-2.5-flash` | 2.5 Flash | no |
| `gemini-pro-latest` | Pro Latest | no |
| `gemini-flash-latest` | Flash Latest | no |

### Display Name Mapping (from original comfy_api_nodes)

The original `GeminiNanoBanana2` node stores display names in the workflow JSON. The conversion script and runtime both map them:

| Original Display Name | Actual API Model Name |
|----------------------|----------------------|
| `Nano Banana 2 (Gemini 3.1 Flash Image)` | `gemini-3.1-flash-image-preview` |
| `gemini-3-pro-preview` | `gemini-3-pro-image-preview` (runtime remap) |

If other display names appear in workflows, add them to the `MODEL_MAP` in `scripts/convert_gemini_nodes.py` and to the runtime mapping in `nodes.py`.

### Important Differences from comfy_api_nodes

- **Output slot order**: `GoogleGeminiDirect` returns `(STRING, IMAGE)` — slot 0 is text, slot 1 is image. The original `GeminiImage2Node` returned `(IMAGE, STRING)` — slot 0 was image. The conversion script swaps link origin slots automatically.
- **Images input**: Now called `images` (plural) and supports batched input up to 14 images via `BatchImagesNode`.
- **Image generation config**: `aspect_ratio` and `resolution` are sent to the API as `imageConfig` inside `generationConfig` when `response_modalities` is `IMAGE` or `IMAGE+TEXT`.
- **System prompt**: Defaults to `GEMINI_IMAGE_SYS_PROMPT` if not overridden.
- **Seed**: The `seed` value is NOT sent to the Gemini API (the original comfy_api_nodes also did not send it). It exists only for ComfyUI's `control_after_generate` frontend feature. The hidden `seed_control` widget (index 4) controls auto-increment/decrement/randomize behavior.
- **Hidden widget caution**: `widgets_values` has **9 entries** but only **8 map to actual inputs**. Index 4 (`seed_control`) is invisible. When manually building a `prompt` dict for the `/prompt` REST API, map inputs sequentially but **skip `widgets_values[4]`** for `GoogleGeminiDirect` nodes.

## FALKlingImage2Video (from comfyui-local-gemini)

Replaces: `KlingFirstLastFrameNode` (cloud API node that calls ComfyUI proxy)

Calls **FAL AI** Kling Video v3 Pro endpoint directly: `POST https://fal.run/fal-ai/kling-video/v3/pro/image-to-video`

### Inputs

| Name | Type | Required | Widget | Notes |
|------|------|----------|--------|-------|
| `api_key` | STRING | yes | yes (0) | Leave empty; use `FAL_KEY` env var |
| `prompt` | STRING | yes | yes (1) | Multiline prompt. Usually connected from `GoogleGeminiDirect` |
| `first_frame` | IMAGE | yes | no | Start frame image tensor |
| `end_frame` | IMAGE | yes | no | End frame image tensor |
| `duration` | INT | yes | yes (2) | 3–15 seconds. Default 5 |
| `generate_audio` | BOOLEAN | yes | yes (3) | Default `True` |
| `cfg_scale` | FLOAT | yes | yes (4) | 0.0–1.0, step 0.1. Default 0.5 |
| `negative_prompt` | STRING | no | yes (5) | Default `"blur, distort, and low quality"` |
| `model` | COMBO | yes | yes (6) | Visual compatibility only. FAL endpoint is fixed to v3 Pro. Default `"kling-v3"` |
| `resolution` | COMBO | yes | yes (7) | Visual compatibility only. FAL infers aspect from image. Default `"1080p"` |
| `seed` | INT | yes | yes (8) | Visual compatibility only. Default 1 |

**Widget order (9 values):**
```
[0] api_key
[1] prompt        (empty when connected)
[2] duration
[3] generate_audio
[4] cfg_scale
[5] negative_prompt
[6] model
[7] resolution
[8] seed
```

### Outputs
| Name | Type | Slot |
|------|------|------|
| `video` | VIDEO | 0 |

### How It Works
1. Converts `first_frame` and `end_frame` IMAGE tensors to base64 data URIs (PNG)
2. Sends both images + prompt to FAL AI Kling v3 Pro image-to-video endpoint
3. Downloads the resulting MP4 from FAL's temporary storage URL
4. Wraps in `InputImpl.VideoFromFile` for ComfyUI `VIDEO` type

### Important Notes
- **Authorization**: Uses `Authorization: Key <FAL_KEY>` header (NOT Bearer token)
- **Images**: Sent as base64 data URIs in the JSON payload — no separate upload needed
- **Dummy parameters**: `model`, `resolution`, and `seed` are exposed for visual compatibility with the original `KlingFirstLastFrameNode` but do not affect the FAL API call (the endpoint is fixed to v3 Pro and infers aspect ratio from the start image)

**Widget order (13 values):**
```
[0] api_key
[1] subject_description
[2] aspect_ratio
[3] duration
[4] generate_audio
[5] seed
[6] seed_control  (auto-generated by control_after_generate, not in INPUT_TYPES)
[7] scene_1_text
[8] scene_1_duration
[9] scene_2_text
[10] scene_2_duration
[11] scene_3_text
[12] scene_3_duration
```

### Outputs
| Name | Type | Slot |
|------|------|------|
| `video` | VIDEO | 0 |

### How It Works
1. Converts `reference_images` IMAGE tensors to base64 data URIs (PNG)
2. Builds `multi_prompt` array from non-empty `scene_N_text` + `scene_N_duration` pairs
3. Sends payload to FAL AI Kling O3 Pro reference-to-video endpoint
4. Downloads the resulting MP4 from FAL's temporary storage URL
5. Wraps in `InputImpl.VideoFromFile` for ComfyUI `VIDEO` type

### Conversion from KlingOmniProImageToVideoNode

Original cloud node had 15 `widgets_values`:
```
[0] model              → drop (cloud-only)
[1] subject_description → keep, becomes index 1
[2] aspect_ratio       → keep, becomes index 2
[3] duration           → keep, becomes index 3
[4] resolution         → drop (cloud-only)
[5] mode               → drop (cloud-only)
[6] scene_1_text       → keep, becomes index 7
[7] scene_1_duration   → keep, becomes index 8
[8] scene_2_text       → keep, becomes index 9
[9] scene_2_duration   → keep, becomes index 10
[10] scene_3_text      → keep, becomes index 11
[11] scene_3_duration  → keep, becomes index 12
[12] generate_audio    → keep, becomes index 4
[13] seed              → keep, becomes index 5
[14] seed_control      → keep, becomes index 6
```

New `widgets_values` (13 values):
```
['', subject_description, aspect_ratio, duration, generate_audio, seed, seed_control,
 scene_1_text, scene_1_duration, scene_2_text, scene_2_duration, scene_3_text, scene_3_duration]
```

**Link remapping:**
- `reference_images` → slot 6 (was slot 0 on cloud node)
- `aspect_ratio` → slot 2 (was slot 1)

### Important Notes
- **Authorization**: Uses `Authorization: Key <FAL_KEY>` header
- **Images**: Sent as base64 data URIs in the JSON payload
- **Scenes**: Only scenes with non-empty `scene_N_text` are included in `multi_prompt`. Empty scenes are skipped.
- **Resolution**: FAL O3 Pro derives resolution from input images; no `resolution` parameter is sent.

### How It Works

3. Sends prompt + reference images + config to FAL Seedance reference-to-video endpoint
4. Downloads the resulting MP4 from FAL's temporary storage URL
5. Wraps in `InputImpl.VideoFromFile` for ComfyUI `VIDEO` type

### Conversion from ByteDance2ReferenceNode

The original cloud node used asset IDs for references. In the local FAL node:
- Asset ID chains (`ByteDanceCreateImageAsset`) are **removed entirely**
- `LoadImage` nodes are **kept** and wired directly to `image_1`..`image_9` slots
- Each `LoadImage.IMAGE` output should be connected to BOTH the FAL node AND any `PreviewAny` sinks that previously displayed the asset

### Real-Human Workflow Pattern

Original workflow structure:
```
LoadImage → ByteDanceCreateImageAsset → PreviewAny (asset_id)
                                      → PreviewAny (group_id)
                                      → ByteDance2ReferenceNode (asset input)
```

Converted structure:
```
LoadImage ──→ FALSeedanceReference2Video.image_1  (slot 9)
          ──→ PreviewAny (asset_id preview, keep for UX)
          ──→ PreviewAny (group_id preview, keep for UX)
```

**CRITICAL**: Do NOT remove `PreviewAny` nodes — they will error with `Required input missing: source`. Wire the `LoadImage` output to them directly.

### Important Notes
- **Authorization**: `Authorization: Key <FAL_KEY>` header
- **Images**: Up to 9 reference images; sent as base64 data URIs
- **Fast endpoint**: `fast=True` → `bytedance/seedance-2.0/fast/reference-to-video`
- **Image resizing**: Images are resized to max 1024px on the long edge before base64 encoding to keep payload size reasonable
