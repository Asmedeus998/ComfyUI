# OpenAI GPT Image Node Input Slots & Conversion

## OpenAIGPTImageDirect Input Slots (for Workflow JSON)

| Slot | Name | Type | Widget | Notes |
|------|------|------|--------|-------|
| 0 | `prompt` | STRING | yes | Multiline prompt text |
| 1 | `seed` | INT | yes | Has `control_after_generate=True` → hidden control widget at index 2 |
| 2 | `quality` | COMBO | yes | `low`, `medium`, `high` |
| 3 | `background` | COMBO | yes | `auto`, `opaque`, `transparent` |
| 4 | `size` | COMBO | yes | `auto`, `1024x1024`, `1024x1536`, `1536x1024`, `2048x2048`, `2048x1152`, `1152x2048`, `3840x2160`, `2160x3840`, `Custom` |
| 5 | `n` | INT | yes | 1–8 |
| 6 | `model` | COMBO | yes | `gpt-image-1`, `gpt-image-1.5`, `gpt-image-2` |
| 7 | `custom_width` | INT | yes | 1024–3840, step 16. Only used when `size="Custom"` |
| 8 | `custom_height` | INT | yes | 1024–3840, step 16. Only used when `size="Custom"` |
| 9 | `api_key` | STRING | yes | Leave empty; uses `OPENAI_API_KEY` env var |
| 10 | `image` | IMAGE | no | Optional reference image for editing (connection only, shape 7) |
| 11 | `mask` | MASK | no | Optional mask for inpainting (connection only, shape 7) |

**Widget order (11 values):**
```
[0] prompt
[1] seed
[2] seed_control  (hidden, auto-generated by control_after_generate)
[3] quality
[4] background
[5] size
[6] n
[7] model
[8] custom_width
[9] custom_height
[10] api_key
```

## Conversion from OpenAIGPTImage1

Original cloud node `OpenAIGPTImage1` had only **3 inputs** in its `inputs` array:
- slot 0: `image` (IMAGE)
- slot 1: `mask` (MASK)
- slot 2: `prompt` (STRING)

And **10 widget values**:
```
[0] prompt, [1] seed, [2] seed_control, [3] quality, [4] background,
[5] size, [6] n, [7] model, [8] custom_width, [9] custom_height
```

The local `OpenAIGPTImageDirect` node expands this to **12 inputs** and **11 widget values** (adding `api_key` at index 10).

**Link remapping when converting workflows:**
- `prompt` link → slot **0** (was slot 2 on cloud node)
- `image` link → slot **10** (was slot 0 on cloud node)
- `mask` link → slot **11** (was slot 1 on cloud node)

**Widget value mapping:**
```python
new_widgets = old_widgets + [""]  # append empty api_key
```

## Critical Differences from Cloud Node

1. **No `seed` sent to API** — The OpenAI Images API does not accept a `seed` parameter. The widget exists only for ComfyUI frontend `control_after_generate` behavior.
2. **`moderation: "low"`** is always sent to match the original cloud node behavior.
3. **No price badge** — Local nodes do not display ComfyUI's cloud pricing UI.
4. **Model validation** is enforced locally before the API call (e.g., custom resolutions only for `gpt-image-2`, transparent background not supported for `gpt-image-2`).
5. **Image downscaling** — Input images are downscaled to ≤2048×2048 pixels before upload.
